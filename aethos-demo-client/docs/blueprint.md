# **App Name**: Aethos Demo

## Core Features:

- Chat Interface: A simple chat interface to send messages to your backend service and display responses.
- RAI Trigger Icon: An icon in the response text box to trigger the sending of the AI response to your backend service for RAI scoring.
- RAI Metrics Display: Display of the RAI score and other ethical AI metrics (biasness, truthfulness, fairness, groundedness) received from your backend service. This could be a popup, inline display, or expandable section.

## Style Guidelines:

- Primary color: Neutral grays for the background and text to ensure readability.
- Accent color: Teal (#008080) to highlight the RAI trigger icon and display the RAI score.
- Clean and simple layout for the chat interface, with a clear separation between user input, AI responses, and RAI metrics.
- Use a distinct and recognizable icon for the RAI trigger, such as a shield or a graph.
- Subtle animation or transition when displaying the RAI score and ethical AI metrics.

## Original User Request:

Along with this score, my backend service will return some other metrices such as biasness, truthfulness, fairness, groundedness, and other responsible AI /Ethical AI metrices. User can click on the icon to get the ResponsileAI(RAI Score) or can view the already generated RAI score. So this app shows how the AI powered application can integrate with my backend services.
